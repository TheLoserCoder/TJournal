# Этапы разработки

1. Foundation: Git, workspace, documentation, rules, lint, tests, Electron shell.
2. Platform: DI composition roots, configuration, logging, diagnostics, database platform.
3. Journal core: portable journal file, migrations, backups, integrity and file watching.
4. Trade core: instruments, minimal trade entry, contracts, persistence and table slice.
5. Detail: executions, risk, tags, notes, attachments and icon import.
6. Accounts: balances, account transactions and commissions.
7. Exploration: filtering, full-screen journal and saved views.
8. Analytics: dashboard, statistics, time series and reports.
9. Product hardening: import/export, recovery, accessibility, performance and Windows packaging.

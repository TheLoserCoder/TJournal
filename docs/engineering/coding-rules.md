# Правила разработки

Корневой [AGENTS.md](../../AGENTS.md) является обязательной исполнимой конституцией проекта. Этот документ поясняет её и не должен ей противоречить.

- Код проходит typecheck, lint, architecture checks и релевантные тесты.
- Внутренние зависимости не пересекают архитектурные границы.
- Конкретные реализации создаются только composition root.
- Публичные use cases и adapters имеют контракты и тесты.
- Значимые архитектурные исключения фиксируются ADR.

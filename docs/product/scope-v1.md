# Границы v1

Сейчас поддерживаются offline vault-журналы: создание или открытие выбранной папки, автоматическое повторное открытие последнего доступного vault, минимальные закрытые сделки (инструмент, дата, USD или процентный результат), простая таблица, RU/EN и темы Auto/Light/Dark.

Один vault — это переносимая папка с `journal.sqlite`, `.tjournal-vault.json`, `attachments/` и `backups/`; перенос выполняется обычным копированием всей папки.

Пока не поддерживаются счета, риск/RR, комиссии, частичные выходы, фильтры, аналитика, открытые позиции, сервер, конфликтное слияние, live market data, брокерские API, произвольные поля и шифрование.

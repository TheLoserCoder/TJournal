# TJournal

TJournal is an offline-first desktop trading journal for recording and analysing closed trades.

## Current status

The project foundation is operational. The initial target is Windows, with an architecture that keeps desktop, future mobile, and optional server adapters separate from the domain.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm check
pnpm make
```

Read [AGENTS.md](AGENTS.md) before making changes. The short project map is in [docs/architecture/code-map.md](docs/architecture/code-map.md).
